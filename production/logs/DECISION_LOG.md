# DECISION LOG

## 2026-11-22 — Documentation architecture
- Permanent project constants and instructions belong in version-controlled GitHub Markdown files.
- The production handoff contains changing status, checklists, milestones, Figma node references, blockers, and next actions.
- GitHub README is the agent entry point. The handoff must point agents to the exact repository URL and required files.
- Current Figma brand books are official visual identity authority.
- Never silently change an approved brand rule or production standard; propose and log changes.

- GitHub repository: https://github.com/everythingmilo/six-brand-content-package (public, owner-created).
- Stable instructions and brand references live in GitHub; `production/HANDOFF.md` is the live status tracker; canonical Figma brand books remain visual authority.
- Agents must read the root README and `project/AGENT_INSTRUCTIONS.md` before acting.
